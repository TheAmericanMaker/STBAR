Panels

Every UI surface is a beveled plate. Highlight runs top + left, shadow runs bottom + right. Invert it and the surface reads as pressed in — that's how input fields and recessed displays look.

Default panel

Brown sepia plate with raised bevel — the universal surface. Pair with bone-colored body text.

Inset panel

Same panel, bevels reversed. Reads as recessed — use it for inputs, display cavities, or terminal readouts.

Iron panel

Cold metal gradient — secondary surface when brown leather is too warm for the context.

Stone panel

Repeating-line texture suggests carved stone. Good for hero blocks and dialog backgrounds.

Buttons

Sharp corners, chunky bevels, no rounded edges anywhere. The press state inverts the bevel and nudges one pixel down + right so you can feel the click.

Use blood for primary destructive actions, fire for confirms, default for neutral, and ghost for secondary/dismiss.

Voice & tone

Do

Short. Imperative. All-caps for verbs that matter. Lean into the marine-radio cadence: "BREACHING. HOLD POSITION."

Numbers, statuses, threat levels. Concrete nouns over abstract ones.

Don't

Don't write corporate. Don't apologize. Don't soften. No exclamation chains, no emoji, no whimsy.

Don't mix metaphors with sci-fi — the world is industrial, infernal, and tactile.

Usage

1. Link the stylesheet

<link href="https://fonts.googleapis.com/css2?family=Black+Ops+One&family=Rubik+Mono+One&family=VT323&family=Press+Start+2P&family=Special+Elite&family=IBM+Plex+Mono:wght@400;500;700&display=swap" rel="stylesheet">
<link rel="stylesheet" href="doom.css">

2. Keep the amazdoom/ folder next to doom.css

The pack is bundled — six TTFs by Amazingmax, all referenced via @font-face. See FONTS.md for attribution. If the pack is ever missing, the fallback chain (Black Ops One via Google Fonts) keeps the system readable.

3. Compose with utility classes

<body class="doom-scanlines doom-vignette">
  <div class="doom-container">
    <h1 class="doom-logo">DOOM</h1>
    <div class="doom-panel">...</div>
    <button class="doom-btn doom-btn--blood">Engage</button>
  </div>
</body>

4. For Tauri apps

Drop doom.css and amazdoom/ into src/ or your asset folder, then import it in your root layout. The Tauri webview is Chromium/WebKit; nothing special needed.

5. For TUIs

See doom-tui.md for ANSI 256 mappings, box-drawing patterns, and an ASCII DOOM logo block.
